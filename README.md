# DevPulse 🎵

Односторінковий веб-застосунок — каталог музичних виконавців з превʼю альбомів та інтерактивними модалками.

🔗 Live demo: https://fedorivrv.github.io/DevPulse/

## Стек
HTML, CSS, JavaScript (Vanilla), Vite

## Моя роль — Team Lead, Front-End Developer
- Розробив ключові UI-фічі: каталог виконавців, динамічні модальні вікна, превʼю альбомів
- Координував команду розробників, проводив код-рев'ю
- Забезпечив чисту архітектуру та адаптивний UI
